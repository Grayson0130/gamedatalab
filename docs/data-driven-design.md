# 数据驱动的游戏设计

## 传统 vs 数据驱动

- 传统：面向对象（OOP）软件开发，引擎做好后玩家使用。
- 数据驱动：持续收集玩家互动数据，用新数据决定下一版场景与引擎变更，优化开发流程。

## 系统架构（简述）

- 软件层：Physics/AI/UI/Audio Engine、渲染。
- 内容层：Character Data、UID Elements、Textures、Models、Scenes。

## 2026 更新

- Live Ops、赛季内容、UGC 与 AI 辅助设计。
- 数据闭环：遥测（Telemetry）→ 分析 → 内容迭代 → A/B 测试。
- AI 生成内容与 NPC 行为，需数据与评估体系支撑。
