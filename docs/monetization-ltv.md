# 游戏变现与 LTV

## 变现手段

- 广告（Ad）
- In-App / In-Game Purchase
- 交叉推广（Cross-promo）
- 订阅（Subscription）

## LTV（Customer Lifetime Value）

简化公式：

```
LTV = 平均购买价值 × 购买频率 × 用户生命周期
```

用途：
1. 控制 CAC（获客成本），保证 LTV >> CAC。
2. 公司估值（早期用户基数大时）。

现代做法：BG/NBD、生存分析、因果 LTV、分层 LTV（按渠道/用户群）。

## 2026 更新

- Live Ops / 赛季制运营成为主流，LTV 需按赛季/内容周期重估。
- 订阅 + Battle Pass 混合变现更常见。
- 隐私合规下，LTV 预测更多依赖第一方数据与建模。
