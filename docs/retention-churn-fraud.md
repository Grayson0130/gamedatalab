# 留存、流失与欺诈检测

## 留存与流失（Churn）

- 流失原因：产品问题（不好玩/体验差）与定价策略（Pricing）。
- 建模：二分类模型（流失 vs 不流失），输出概率；离线训练→在线服务→实时打分→阈值触发挽留（优惠、免费订阅 1–3 个月）。

## 欺诈检测（Fraud Detection）

- 场景：假账号、盗用支付、作弊。
- 方法：异常检测（Anomaly/Outlier Detection）；游戏场景需人工验证环节，避免误判影响体验。
- 流程：历史数据训练 → 实时数据流入 → 判定 → 验证 → 处理 → 循环迭代。

## 2026 更新

- 流失预测使用序列模型/深度学习（Transformer、RNN），结合实时行为。
- 欺诈检测对抗更复杂：bot farms、AI 作弊，需图神经网络（GNN）、行为序列模型与设备指纹。
- 实时风控与可解释性（XAI）要求更高。
