# 用户获取（User Acquisition）

## 用户获取漏斗

1. **Acquisition**：下载/注册
2. **Activation**：首次使用/激活
3. **Retention**：回流与持续使用
4. **Referral**：社交裂变
5. **Revenue**：付费转化

核心指标：**Conversion Rate（转化率）**。

## 数据技术

- 邮件营销：控制送达率、打开率、点击率、落地页流量。
- 留存分析：DAU/MAU、Churn/Turnover analysis。
- 用户分群（Segmentation）：按属性/行为分组，触发不同激励。

## 2026 更新

- 获客渠道扩展到 TikTok/短视频、网红/KOL、跨端（PC/主机/移动）。
- 归因更复杂：SKAdNetwork、隐私沙盒、多触点归因（MTA）与 MMM。
- 实时个性化：基于事件流的实时分群与消息推送（Kafka/Flink + CDP）。
