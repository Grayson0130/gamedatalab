# 可复现作品集

三个案例共享同一套合成遥测、明确的时间口径和实际生成结果。全部为教学演示，不是客户项目或上线收益。

| 案例 | 核心问题 | 已实现 |
| --- | --- | --- |
| [留存与 LTV](ltv-analysis/README.md) | 同龄渠道队列是否覆盖获客费？ | SQL 成熟队列、退款与零成本边界 |
| [流失风险](churn-prediction/README.md) | 早期活跃能否预测下一周不活跃？ | 时间窗口、embargo、可解释基线与评估 |
| [教程实验](experimentation/README.md) | 新教程在固定终点是否提高完成率？ | ITT 分母、差值区间、p 值与 SRM |

统一复现：在仓库根目录运行 `python -m gamedatalab`，然后查看 [生成报告](../reports/demo/README.md)。每个项目目录给出问题、方法、结果位置与局限；不是三个互不相干的占位目录。

下一步可以增加有曝光日志和时间切分的推荐案例，或有独立双盲评审的多语言 LQA 评估集。这些是待扩展项目，未计入当前完成能力。
