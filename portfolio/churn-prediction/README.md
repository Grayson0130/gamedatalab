# 案例：无未来泄漏的流失风险基线

**问题**：D0–D6 活跃天数能否预测 D7–D13 无 session？这是未来一周风险，不是永久流失，也不是发优惠券的收益。

执行 `python -m gamedatalab`，查看 [结果 JSON](../../reports/demo/summary.json) 的 `churn` 和 [报告](../../reports/demo/README.md)。

## 方法

- [`churn.sql`](../../sql/churn.sql) 严格分离特征与标签窗口，排除未成熟标签。
- 训练安装日≤2026-08-10，测试安装日≥2026-08-18，七天安装队列隔离。
- 用训练活跃天数分桶估计 Beta(1,1) 平滑风险；未知桶回退到训练先验。
- 报告测试基准率、ROC AUC（并列分数平均秩）、Brier、常数先验 Brier 和 precision@10%。

## 解释

对照常数基线说明模型是否有概率预测收益。precision@10% 是固定容量下的风险筛选示意，分数并列时按 user_id 固定排序；不代表该人群最值得补贴。单类测试样本的 AUC 为 NULL，而非伪造 1.0。

## 验证与限制

边界测试保证 D7 活动不会进入特征，D14 事件不改写标签；生成种子可复现。模型没有部署，未做因果干预或外部验证。后续树模型应在训练/验证时间窗口调参，不能反复观察当前测试集后宣称泛化提升。
