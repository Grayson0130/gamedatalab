# 案例：固定终点教程实验

**问题**：随机分配的新教程在 D0 完成率上有多大差异，区间是否支持业务判断？

执行 `python -m gamedatalab`。实际输出见 [报告](../../reports/demo/README.md) 与 [summary.json](../../reports/demo/summary.json) 的 `experiment`。生成器将处理效应预设为 0.035，样本估计与这个参数不必完全一致。

## 方法

每名玩家 50:50 随机分组，全部合资格分组用户进入分母，不因未完成而删除。SQL 去重完成用户；分析计算绝对与相对差值、Wald 95% 区间、pooled z 检验与 χ²(1) SRM。SRM 失败时输出调查提示，不自动得出上线结论。

## 解读与限制

默认样本是教学规模，不保证检出设定效应。未覆盖护栏指标的实际实验，所以即使主要指标显著也不能据此上线真实教程。低成功/失败数拒绝正态近似；非独立用户、非等分配和序贯观察应改用适合的方法。

测试覆盖零差异、已知 0.1 绝对提升、明显分组失衡、越界计数与稀疏事件。详见 [实验方法](../../docs/experimentation.md)。
