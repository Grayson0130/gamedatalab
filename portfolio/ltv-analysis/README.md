# 案例：成熟队列留存与渠道收益

**问题**：相同安装年龄下，不同合成渠道的净交易额和简化贡献是否覆盖获客成本？

数据为 1,200 名合成玩家及交易/退款事件。执行 `python -m gamedatalab`，读取 [报告](../../reports/demo/README.md)、[留存 CSV](../../reports/demo/retention.csv) 和 [结构化结果](../../reports/demo/summary.json) 的 `ltv`。

## 方法

[`retention.sql`](../../sql/retention.sql) 计算精确 UTC 日历日留存，重复 session 先去重，未成熟 D30 保留空值。[`ltv.sql`](../../sql/ltv.sql) 只纳入完整 D0–D30 队列，先按玩家聚合避免 join 放大，退款进入负收入；自然渠道成本为零时 ROAS 为 NULL。

## 结果与决策

随包报告记录实际运行值，不在项目说明中另抄一份可能过期的数字。先对比同龄队列，再审查人数、地区与价格差异；若简化贡献 ROAS 小于 1，只能说明当前窗口未回本，不能断言全生命周期必亏。

## 验证与限制

测试覆盖手算 10 美元充值、2 美元退款、2 美元获客成本，以及最新队列与重复事件。统一 30% 费用是教学假设。没有真实媒体归因、服务成本、税费或长期预测，不从合成渠道结果给出投放建议。
